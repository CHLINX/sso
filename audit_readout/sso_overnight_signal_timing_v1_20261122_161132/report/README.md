# SSO 隔夜訊號可得時間與進場時點驗證 v1.0.1

F02/F04 只使用當日開盤價與歷史收盤資料，訊號於當日開盤價形成後即可觀察。

本研究固定比較：當日開盤參考價進場、當日收盤集合競價進場、次日開盤進場。三種模型使用相同訊號及同日完整案例股票池。

開盤參考價模型是樂觀上界代理，不代表可按開盤價成交；收盤集合競價模型假設有能力於當日收盤前送單，實際成交仍需委託簿／分時資料驗證。

方向只由已封存 2016-2021 baseline 再現；不使用驗證／後段資料更改方向，也不做權重最佳化。

成本：單邊手續費 0.1425%、賣出交易稅 0.3%、單邊滑價 0.1/0.2/0.3/0.5%。每日 TopN 是 cohort，不是複利資金帳戶。
