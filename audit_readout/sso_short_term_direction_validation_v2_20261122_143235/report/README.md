# SSO 短線因子方向凍結與反向訊號驗證 v2.0

方向只由 2016-2021 開發期決定：factor-horizon 的 HAC p 值經 32 組 BH 修正後 q<0.05 才凍結 HIGH/LOW；後續驗證期及 2024+ 不改方向。

HIGH 表示買入原始因子值最高者；LOW 表示買入原始因子值最低者（仍為 long-only，不是放空）。未達開發期統計門檻者標示 UNRESOLVED，不進入方向固定的組合績效。

持有期：訊號日收盤形成，次一交易日開盤進場，第 H 個交易日收盤出場。Top1/3/5/10/20 為每日等權 cohort，非完整資金帳戶複利回測。

成本：單邊手續費 0.1425%，賣出稅 0.3%，雙邊滑價分別測試單邊 0.1/0.2/0.3/0.5%。最低手續費、價差、漲跌停排隊、部分成交仍未建模。

2024+ 並非完全未曾檢視的純新樣本；仍需 survivorship bias 與完整資金帳戶回測。
