## 當日行情查詢時間門檻

- 時區：Asia/Taipei。
- 台灣時間 17:00 前，不查詢當日行情；本次最多查詢至前一日。
- 台灣時間 17:00 起，才允許查詢當日行情。
- 官方 API 回應空資料時，狀態列為 `WAITING_FOR_OFFICIAL_DATA`，不列為 `REJECTED`，也不據此推定休市。
- 空回應的 gzip 原始回應及 SHA256 會保留；該日期不會寫入增量，也不會推進最後行情日，後續執行會重新查詢。

## 即時檢查

每次官方 API 下載後立即執行：

- HTTP/JSON 回應檢查
- 行情欄位檢查
- 列數及母體範圍檢查
- 代號及重複鍵檢查
- 成交量與零成交量比例
- OHLC 缺值比例
- OHLC 價格關係
- 市場及日期檢查

通過才會寫入增量資料。

未通過資料只保存 gzip 原始回應及錯誤原因，不會混入標準化行情。
