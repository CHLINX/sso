## 本版目的

1. 統計 change_sign 原始值及 Unicode 編碼。
2. 統計 change_note_raw 原始文字。
3. 對照前版逐筆計算方向，找出符號辨識規則的落差。
4. 交叉檢查原始市場與公司基本資料名單的代號。
5. 列出缺少前收的證券代號與日期。

## 本版限制

公司基本資料名單命中，只代表公司代號與公司資料相符，
不能單獨證明證券代號一定是普通股。

公司基本資料名單未命中，也不能直接推斷為 ETF。

本版不自行建立正式漲跌符號映射，不修改原始行情或語意層。
