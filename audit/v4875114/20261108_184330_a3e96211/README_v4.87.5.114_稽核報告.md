## 三、資料處置原則

### 1. 官方獨有資料

若官方原始來源確實有該筆行情，而候選資料集沒有，應列入補入評估，不可當成錯誤資料刪除。

### 2. 倍率變化

公司行動資料的日期窗命中，只能視為關聯線索，不能直接當成倍率已核實。仍須確認證券代號、事件類型、有效日及價格參數。

### 3. 有量無 OHLC

成交量紀錄應保留。缺少完整 OHLC 時，應隔離於 OHLC 計算流程，而不是直接刪除整筆原始成交紀錄。

### 4. v4.51 兩次下載差異

比較以自然鍵為基礎，不以 CSV 列順序判定。核心行情欄位與非核心欄位差異分開記錄。
